# 🚨 Local AI Session Compaction & Restart Protocol

When your active conversation context climbs near the 80K-90K limit, the legacy VS Code interface will attempt to crash the stream mid-sentence. Execute this script sequence to drop your memory load back to baseline instantly without losing an ounce of project state.

---

## 🛑 STEP 1: Execute the Emergency Compaction Prompt
Stop your active development thread immediately. Copy and paste the exact text block below straight into your stuck chat panel and hit enter:

```text
HALT GENERATION. Activate Emergency Compaction Protocol. Do not generate code features. Output a compressed summary of our built features, the current architectural state, and the remaining sequential checklist tasks for our TODO.md file right now.
```

---

## 📝 STEP 2: Lock the Project Coordinates
1. Highlight and copy the markdown checklist summary the model prints out.
2. Open your root `TODO.md` file on your drive.
3. Overwrite the contents with the new checklist block and save the file (`Cmd + S`).
4. Look at your chat panel and copy any raw Swift code blocks it successfully generated on its last turn. Paste them safely into your active workspace script tabs.

---

## 🧹 STEP 3: Purge the Memory Cache
Click the **New Chat (+)** drawer button at the top of your VS Code chat panel interface. This forcefully wipes the old, bloated 90,000-token conversational history out of your physical RAM channels, dropping your context footprint cleanly.

---

## ⚡ STEP 4: Boot Up the Hyper-Drive Thread
In your brand-new, clean chat input box, paste this exact file attachment targeting string to re-align the agent's principal systems engineer mindset at your record 2,658 tokens-per-second processing speed:

```text
@file:TODO.md @file:WizardState.swift 

Read my active checklist coordinates. Transition instantly into non-thinking code generation mode. Output the production-ready code needed to execute our next sequential micro-step.
```
